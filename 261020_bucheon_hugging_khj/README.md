# AI vs 나 빈칸 퀴즈

Hugging Face의 한국어 BERT 모델(`klue/bert-base`)을 활용한 터미널 퀴즈 게임입니다.
문장 속 빈칸에 들어갈 단어를 **나와 AI가 함께 맞히거나**, 반대로 **AI가 헷갈릴 만한 문제를 직접 내서 AI를 속이는** 두 가지 모드로 즐길 수 있습니다.

## 사용한 모델

| 항목 | 내용 |
|---|---|
| 모델 | [`klue/bert-base`](https://huggingface.co/klue/bert-base) |
| 작업(Task) | [Fill-Mask](https://huggingface.co/models?pipeline_tag=fill-mask) (빈칸 채우기) |
| 만든 곳 | KLUE (한국어 자연어 이해 평가 프로젝트) |
| 크기 | 약 1억 개 파라미터, 다운로드 약 400MB |
| 실행 방식 | Hugging Face Hub에서 모델을 내려받아 **내 컴퓨터에서 직접 실행** |

## 주요 기능

### 1. 맞히기 모드 (AI vs 나)

- `problems.txt`의 문제 중 5개를 무작위로 출제합니다.
- 내가 답을 입력하면, AI의 답과 함께 채점합니다.
- AI가 생각한 **후보 단어 5개를 확률 막대그래프**로 보여 줍니다.
- AI가 **내 답을 몇 % 확률로 예상했는지**도 알려 줍니다.
- 최종 점수로 나와 AI의 승패를 가립니다.

### 2. 속이기 모드 (내가 문제 내기)

- 정답 단어를 `[ ]`로 감싼 문장을 입력하면, AI가 그 빈칸을 맞힙니다.
- **사람은 쉽게 맞히지만 AI는 헷갈리는 문장**을 만드는 것이 목표입니다.
- 내 정답이 AI 후보 몇 위에 있는지로 판정합니다.

| 내 정답의 AI 순위 | 결과 | 점수 |
|---|---|---|
| 1위 | ❌ 실패 (AI가 맞힘) | 0점 |
| 2위 | 🎉 성공 | 3점 |
| 3위 | 🎉 성공 | 2점 |
| 4~5위 | 🎉 성공 | 1점 |
| 5위 밖 | ⚠️ 무효 (너무 엉뚱한 문장) | 0점 |

AI가 거의 맞힐 뻔한 문장으로 속일수록 점수가 높고, 아무도 못 맞힐 엉뚱한 문장은 무효로 처리해 반칙을 막습니다.

## 💬 사용 예시

### 맞히기 모드

```
=== 🧠 빈칸 퀴즈 ===
1. 맞히기 모드 (AI vs 나)
2. 속이기 모드 (내가 문제 내기)
3. 종료
선택 : 1

[1/5] 대한민국의 수도는 ____이다.
나의 답 : 서울

정답 : 서울
나   : 서울 ⭕
AI   : 서울 ⭕

AI가 생각한 후보:
  1위 서울     ████████████████ 81.2% ← 정답
  2위 부산     █ 4.3%
  3위 어디     █ 2.1%
  ...

💡 AI는 내 답 '서울'을(를) 81.20% 확률로 예상했어요.

현재 점수 → 나 1 : 1 AI
```

### 속이기 모드

```
[1/3]
문제 : 나는 아침마다 [커피]를 마신다.
AI에게 낸 문제: 나는 아침마다 ____를 마신다.

AI가 생각한 후보:
  1위 우유     ███████ 35.0%
  2위 커피     █████ 24.8% ← 내 정답
  3위 물       ███ 15.1%
  ...

🎉 성공! 내 정답이 AI 후보 2위였어요. +3점
```

> 위 예시의 확률 값은 설명을 위한 것으로, 실제 결과는 다를 수 있습니다.

## 동작 원리

```
문장 입력 → 토큰(조각)으로 쪼개기 → BERT가 문장 앞뒤 문맥 분석
→ 빈칸 자리에 사전의 모든 조각(약 3.2만 개)별 확률 계산 → 상위 5개 후보 출력
```

1. **토큰화**: 모델은 문장을 미리 정해진 조각 사전의 조각들로 나눕니다.
   예: `대한민국의 수도는` → `대한민국` `##의` `수도` `##는`
2. **문맥 분석**: BERT는 빈칸의 **앞과 뒤를 동시에** 보고 빈칸 자리의 의미를 파악합니다.
3. **확률 계산**: 빈칸 자리에 들어갈 수 있는 모든 조각에 확률을 매기고, 가장 높은 5개를 후보로 보여 줍니다.
4. **내 답의 확률**: `pipeline`의 `targets` 옵션으로 특정 단어의 확률만 따로 계산합니다.

```python
fill = pipeline("fill-mask", model="klue/bert-base", top_k=5)
fill("대한민국의 수도는 [MASK]이다.")                    # 상위 5개 후보와 확률
fill("대한민국의 수도는 [MASK]이다.", targets=["서울"])  # '서울'의 확률
```

## 한계점

- **정답은 한 조각(토큰)짜리 단어만 가능**: BERT는 빈칸 하나에 조각 하나만 채울 수 있습니다. `외양간`처럼 `외양` + `##간` 두 조각으로 나뉘는 단어는 맞힐 수 없어서, 이런 문제는 자동으로 제외됩니다.
- **사실이 아닌 확률로 답함**: 모델은 지식을 이해하는 것이 아니라 "이 자리에 자주 오는 단어"를 확률로 고릅니다. 그래서 문법적으로 자연스러운 다른 단어를 고르며 상식 문제를 틀리기도 합니다.
- **작은 모델**: 약 1억 개 파라미터의 base 모델이라, 속담이나 드문 표현은 잘 모를 수 있습니다. `quiz.py`의 `MODEL_NAME`을 `klue/roberta-large`처럼 더 큰 모델로 바꾸면 정확도가 올라가지만, 다운로드 용량과 실행 시간이 늘어납니다.
